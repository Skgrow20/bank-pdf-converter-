Tally Server Connection

Configure Tally Prime connectivity. If Tally Prime is running on a Remote PC, Server, or Local Network, enter its IP address or hostname below.

💡 Remote PC / Server Setup Steps:
  1. In Tally Prime on Remote PC: Press F1 (Help) → Settings → Connectivity.
  2. Set Client/Server configuration to Both or Server.
  3. Set Port to 9000 and Enable ODBC to Yes. Restart Tally Prime.
  4. On Remote PC: Open Windows Defender Firewall → Add Inbound Rule allowing TCP Port 9000.
  5. Enter the Remote PC's IP address (e.g. 192.168.1.X) above and click Test & Save.
